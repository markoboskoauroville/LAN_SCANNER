# TAKEOVER: LAN Scanner (Mantra)

Public, unpromoted repository: no README and no description by rule (MANTRA_MANIFEST modules/repo-privacy.md). This file says what the project is and how to get from a fresh clone to everything installed.

## What it is
A Mac app (Swift, macOS 14+) showing every device on the network this Mac is on now. One window, one button: SCAN (STOP while it runs); a scan also runs when the window opens. Table: Name, IP, MAC, Maker, Kind, Seen; header: network name, this Mac's address, subnet, router, device count; "OTHER NETWORK <iface>" buttons when a second LAN interface is up; a device that vanished stays grey as "gone" until the next launch. A row with no name shows the maker ("Murata device", "Private address device"), dim; a name is never invented. Click a row = copy its IP. Asked by Marko on 21.11.2026 (words in momentaryupdates.md); "store" is read as the star.

## From clone to installed (nothing compiles on the Mac)
1. Clone: `git clone https://github.com/markoboskoauroville/LAN_SCANNER ~/Developer/LAN_SCANNER`. Commit identity for this public repo: `<id>+markoboskoauroville@users.noreply.github.com` (modules/building-repos-public.md).
2. The only compiler is GitHub Actions (`.github/workflows/mac-swift.yml`, macos-15) on a push to main: one-title guard (`check_one_title.sh`), the IEEE maker table (`tools/make_oui.py` writes build/oui.tsv, never fails the build), `build.sh` (swiftc, icon from icon/six_1024.png, Info.plist), `--selftest` (a red run is a real defect), release `vN` marked Latest with `app.zip`. The version is `let VERSION = N` in app/App.swift, whole numbers; bump it for every release.
3. Install: `gh release download --repo markoboskoauroville/LAN_SCANNER --pattern app.zip -D /tmp/lan --clobber`, `ditto -x -k /tmp/lan/app.zip /Applications`, `xattr -dr com.apple.quarantine "/Applications/LAN Scanner (Mantra).app"`, then `codesign --force -s "Mantra Apps" "/Applications/LAN Scanner (Mantra).app"` (certificate "Mantra Apps", modules/mac-app-signing.md). Bundle id `community.auroville.lanscanner`.
4. The `lanscan` command: a small Python script at ~/.local/bin/lanscan (chmod +x) that runs `"/Applications/LAN Scanner (Mantra).app/Contents/MacOS/LAN Scanner (Mantra)" --json`, and prints a table (`lanscan --json` raw, `--iface en5` another interface). It lives in ~/.local/bin, not in this repo; its text is in ~/Downloads/API "TERMINAL COMMANDS.md" (### lanscan). Queen answers "which devices are on my network" through it (groq_ai_studio queen_skills/lan-scan.md, `chat_lan` in qwen_app/ops_hands.py).
5. The star row: add to ~/Developer/STAR_SWIFT/rows.json the row `{"key":"lanscanner","group":"Networking","kind":"app","app":"/Applications/LAN Scanner (Mantra).app","bundle":"community.auroville.lanscanner", ...}` and to icons6/icons.json `["lanscanner","LAN","SCN","sf:wifi"]` (category Mac tools), then copy rows.json to ~/.config/star-rows.json (the star reads it at every opening). The icon is made by STAR_SWIFT/icons6/six_icon.swift and kept as icon/six_1024.png.

## Flags (the same binary)
`--json [--iface en5]` one scan, JSON on stdout (network, interface, ip, cidr, gateway, deviceCount, notes, permissionSuspect, error, devices[{ip, mac, name, label, maker, kind}]); `--selftest` pure-logic checks (CIDR, /22 cap, ARP lines, OUI, kinds, labels, DNS/UPnP parsing, gone merge, fixture); `--studio-shot <png> [--width N]` renders the window content off screen; `--fixture <file.json>` feeds made-up scans, one per SCAN press, the last one repeating (fields: delay, net{iface,ip,prefix,gateway,title}, noNetwork, notes, error, permissionSuspect, devices[{ip,mac,name,maker,kind}]; top-level `others` for the second-interface picker); `--debug-permission` forces the amber PERMISSIONS state and its error line; `--version`.

## Engine (app/Engine.swift, app/Discover.swift, app/Model.swift)
Interface with the default route (route -n get default, getifaddrs; utun, bridge, awdl, ... skipped); sweep with an unprivileged ICMP socket plus a NetBIOS node-status query over UDP/137 to every host (batches of 64, two passes, /22 cap with a note in the window); the ARP table read with sysctl (NET_RT_FLAGS, RTF_LLINFO; rt_msghdr is 92 bytes) as the truth, `arp -an` as fallback. Names, best first: Bonjour (NetServiceBrowser over the fixed type list that Info.plist NSBonjourServices repeats), mDNS reverse lookup (PTR to 224.0.0.251:5353 and unicast to the device), SSDP/UPnP (M-SEARCH, then friendlyName/modelName/deviceType from the description XML, only from the device's own address), reverse DNS, NetBIOS; empty when none answer. Maker from Resources/oui.tsv (CI, IEEE list) or the 325-prefix fallback in app/Oui.swift (taken from that same list); a locally administered MAC is "Private address". Kind is a guess; Unknown is allowed, wrong is not. Errors are shown, never silent.

## Local Network permission (macOS 15)
Info.plist has NSLocalNetworkUsageDescription, NSBonjourServices and NSAllowsLocalNetworking (UPnP descriptions are plain http). Without the permission sends fail or the ARP table stays empty: the window shows an error line and the amber PERMISSIONS button (opens System Settings > Privacy & Security > Local Network; checked again on every click). The permission is recorded against the code signature: always sign with "Mantra Apps" and keep the bundle id, or Marko must switch it on again. The app never opens Settings by itself.

## Window
Plain NSWindow, resizable, frame autosave, minimum content 780 x 360 enforced for programmatic resizes too, own title once (check_one_title.sh), version visible, window X quits the app, every control an Accessibility button with identifier (scan, stop, permissions, net-<iface>, row-<ip>) and a readable AXDescription (SwiftUI needs `.accessibilityElement(children: .ignore)`, `.accessibilityLabel` and `.accessibilityAction`). Asks to update at start (Updater.swift, repo LAN_SCANNER).

## Not proven
Bonjour names on a network that really advertises services; a real network wider than /22; two real LAN interfaces; the Local Network prompt for a fresh signature; the Updater swap itself (the question was shown, Marko answers it).
